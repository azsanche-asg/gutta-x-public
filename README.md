# GUTTA-X

A touch-first cyber-noir arena game prototype for iPhone and iPad.

[GUTTA-X at Burrito’s Labs](https://burritoslabs.com/catalogue/gutta-x/)

## Technology

C#, Unity and native touch input.

## Architecture

The prototype separates room generation, validation and combat. The arena uses short encounters and readable touch zones to test movement, aiming and cover.

## Product behavior

The current scope is a playable arena slice. Connected sectors and progression remain in development.
